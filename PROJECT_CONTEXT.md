# PROJECT_CONTEXT — RelanceClient IA

## Objectif

Créer un MVP SaaS simple permettant aux artisans de suivre leurs devis et de relancer leurs prospects avec validation humaine avant envoi.

## Cible

Artisans du bâtiment :
- plombiers
- électriciens
- menuisiers
- rénovateurs
- peintres
- carreleurs

## Règle produit principale

Aucun email de relance ne doit être envoyé automatiquement sans validation explicite de l’utilisateur.

## Stack recommandée

- Next.js 14
- TypeScript
- Tailwind CSS
- shadcn/ui
- Supabase PostgreSQL
- Supabase Auth
- Prisma
- Resend
- Zod
- Vercel

- docs/spec.md

## Priorité MVP

1. Authentification
2. Gestion prospects
3. Gestion devis
4. Statuts de relance
5. Génération de message de relance
6. Validation humaine
7. Envoi email via Resend
8. Dashboard simple
